# F1 Race Summarizer & RAG Chatbot

A chatbot that answers Formula 1 race questions from ingested data. It routes each question to a SQL database for statistics, a vector database for race reports and steward decisions, or both, then answers with cited evidence and a dashboard that matches the question. Built with Python, FastF1, ChromaDB, SQLite, the Gemini API and Streamlit, entirely on free tiers. Unofficial project, not affiliated with Formula 1, the FIA or any team.
